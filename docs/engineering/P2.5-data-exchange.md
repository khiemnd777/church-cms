# P2.5-r1 — Import/export có đối soát

Authority và acceptance: [CHURCH-P2.5](../tasks/CHURCH-P2.5.md). P25-01–05 local/synthetic; không commit/push/deploy/dữ liệu thật, dừng trước P2.6. Implementation đã được Khiêm nghiệm thu ngày 2026-11-12; mở P2.6 planning theo task, chưa released.

## Ownership và dữ liệu

`api/data-exchange` sở hữu phiên nhập, file xuất và khóa nguồn. `Members.exchangePort()` cung cấp preview validation/candidates/reference queries/export read model/create trong transaction có sẵn. Hàm tạo dùng chung với create API P2.2; không nested transaction hay HTTP từng dòng. Families sở hữu family metadata/history và Organization sở hữu settings/units; public read methods hỗ trợ session để snapshot nhất quán. Chỉ Members ghi members/member_history; không ghi xuyên module.

- `exchange_imports`: actorKind/actorId/churchId, source/digest, các sheet chuẩn hóa, lựa chọn sheet/mapping/decisions, version/state/outcomes, plan/context/fingerprints/batches. TTL24h, hard expiry tại mọi request; không lưu file upload gốc. Tổng JSON chuẩn hóa≤5MiB để chặn phình document.
- `exchange_sources`: unique index `(churchId, source, externalId)` → memberId; giữ lâu hơn ledger/phiên nhập. Lưu jobId/actor/action/reason/sourceDigest làm nguồn gốc đối soát, không TTL.
- `exchange_exports`: snapshot allowlisted columns/rows, file bytes/count/SHA256/format, actor/realm/church, TTL1h. Tổng rows JSON≤5MiB, file≤5MiB; snapshot+artifact+audit+ledger atomic.
- Ledger Operations v2 giữ24h replay/48h TTL. Namespace `exchange`, receipt chỉ original actor/realm/church. Audit lưu count/digest/column set/filter digest/job/operation/actor; không raw rows/file hoặc filter chứa tên/phone. Lịch sử hồ sơ/gia đình tiếp tục theo nghiệp vụ hiện hành.

Policy version6 thêm `data:import`, `data:export` cho owner/pastor/secretary. Không suy từ members:read; ministry_lead/treasurer/member bị chặn cả jobs/template/count/file. Role matrix readonly hiển thị Nhập/xuất. Fence xác thực/credential/session/account/church trong transaction; role/account change/suspension và hard expiry được kiểm lại ở backend, kể cả download và replay. Không public URLs.

## File contracts

`contracts.ts` là danh mục fields/cột export, labels/DTO/limits. Template CSV/XLSX có một dòng synthetic; người nhập phải thay mẫu. `externalId` ổn định trong source, `memberCode` chỉ dùng đối chiếu/liên kết existing. Các enum dùng identifiers hiện hành, hướng dẫn tại UI.

Import≤1000 data rows tổng các sheet,5MiB,40columns,4096chars/cell; header≤200chars/unique/nonblank. CSV UTF-8/BOM/RFC4180 quoting/embedded newline; không tự strip prefix bảo vệ hoặc đoán delimiter. XLSX≤20sheets, chọn sheet rõ, actual ZIP expanded≤32MiB/200entries, worker10s và tối đa2 readers mỗi process. Giới hạn actual decompression trước ExcelJS; từ chối XML DTD/entity/formula/external relationships/macros/embeddings/unsafe paths/encrypted/unsupported cells. Không fetch URL từ file; không evaluate/cached formula. Date cells theo date1904/1900 và chỉ ngày không có giờ; serial60 bị từ chối, ngày trước1900-03-01 có điều chỉnh leap-bug. Template ưu tiên ngày ISO text. Bảo toàn phone/code dạng string; không khôi phục số0 khi file đã mất thông tin.

Dependencies ExcelJS4.4.0, fflate0.8.3; uuid override11.1.1 dùng bởi ExcelJS v4, sửa advisories khi qualification. Đã đọc source/official docs và audit; không tự nâng dependencies khác. Nguồn: https://github.com/exceljs/exceljs, https://github.com/101arrowz/fflate, RFC4180 và OWASP CSV Injection. CSV export quote/escape toàn bộ ô, thêm apostrophe cho ô nguy cơ công thức (kể cả whitespace/full-width); đếm và thông báo protectedCells. Không tuyên bố an toàn/roundtrip trên mọi spreadsheet. XLSX ghi string cells/format text, không formula. CSV download dùng BOM/CRLF.

## HTTP

Prefix `/api/v1/{owner/}churches/{churchId}/data-exchange`. Owner và church cookie/CSRF tách biệt. JSON body giữ16KiB; upload endpoint riêng stream-bound5MiB, không nới global JSON. Mutations UUID; patch/prepare/batches If-Match; strict request schemas.

| Route | Method | Contract |
|---|---|---|
| templates?format=csv/xlsx | GET | Sample/template protected bằng data:import |
| imports | POST | Raw bytes; X-File-Format csv/xlsx, X-Import-Source URI-encoded; trả importId/operationId |
| imports | GET | Actor-only, keyset cursor/limit25 default/100max, còn hạn |
| imports/{id} | GET/PATCH | DTO/version; selectedSheet/mapping/decisions; thay mapping/sheet chỉ trước dòng đầu đã xử lý |
| imports/{id}/rows | GET | offset≤1000/limit25–100, derived validation/candidates/outcome/counts; no writes domain |
| imports/{id}/prepare | POST | Body{}, If-Match; không lỗi/review chưa giải quyết; trả version/importId, GET lấy token/counts |
| imports/{id}/batches | POST | {token,nextBatch,consent:true}, If-Match/UUID; đúng lô kế tiếp |
| imports/{id}/reconciliation?format=... | GET | Kết quả từng dòng created/linked/skipped/not_written; protected file |
| exports/preview | POST | {filters,columns,format}; count/asOf/previewToken, không artifact/domain writes |
| exports | POST | Cùng payload + previewToken/UUID; re-query snapshot/hash/policy trước tạo file |
| exports/{id}/download | GET | Bytes cố định, X-File-Digest SHA256 bytes; fresh fence/ACL/expiry/no-store |
| operations/{id} | GET | Safe receipt namespace exchange; không PII/raw file |

## Review và batches

Source đã có → skip, hiển thị khác biệt khi có. Mã thuộc viên exact phải được xác nhận link, không ghi đè. Source/memberCode bất đồng hoặc cross-tenant/missing/merged references → lỗi. Tên+DOB hoặc phone matching chỉ là candidates (10 hiển thị tối đa); cùng file cũng cần quyết định khi tương đồng. Explicit create/link cần reason khi xử lý warning. Dòng lỗi có thể chủ động skip; duplicate source trong file chỉ một dòng được giữ. Bỏ qua không giữ source identity cho một hồ sơ chưa xác định.

Tạo mới active theo Members rules; consent từng dòng true và khai báo nguồn ở bước commit. Family existing chỉ attach active, không sửa metadata/area; new familyKey metadata nhất quán≤100người/≤1head, không infer head. Active exact normalized unit name+kind, không fuzzy/auto-create. Auto age + explicit service memberships dùng Organization.assignment. Caregiver/code/scope/date/type/visitor/baptism validation hiện hành.

Plan gắn version/mapping/decisions/input/target+candidates+family versions, settings/catalog/policy/business day. Group new family không chia lô. Lô≤100 gồm domain/history/audit/source registry/outcomes/ledger trong một transaction. Kiểm lại context và fingerprints trước ghi; thay đổi phải re-review. Sau lô thành công chỉ cập nhật baseline ảnh hưởng do chính lô đó trong cùng snapshot. Không toàn-file transaction.

State review→ready→partial/completed. Known abort rollback toàn lô, mark review/partial và xóa plan; giữ các lô trước. Unknown commit không đổi trạng thái đoán; trả operationId và original intent protected qua reauth, chỉ người dùng yêu cầu lookup/retry. Resume phiên còn hạn/remaining rows; mapping bất biến sau khi bắt đầu. UI có dừng sau lô hiện tại, không giả rollback lô đã commit.
