## Ownership / giao dịch

PrepClasses sở hữu `prep_courses`, `prep_enrollments`, `prep_meetings`, `prep_class_history`. Public `PrepMembers` kiểm eligibility/picker, `AttendanceMembers.candidatesForIds` cung cấp snapshot current identity và explicit family/area read model; Organization cung cấp labels qua port hiện có. PrepClasses không đọc/ghi Attendance collections trực tiếp.

Attendance sở hữu sessions/participants/history. Session ordinary vẫn scope church/unit; class session thêm `prepClass {courseId,meetingId,lessonId,kind}` do application port tạo server-side với scope church/unit=null. Public HTTP create không chấp nhận field này. Schema cấm class source với unit scope. Internal createPrep cùng Mongo transaction với meeting/history/audit/Operations ledger, không có orphan session khi abort.

`PrepAttendanceSource` là public read/fence implementation của PrepClasses, được inject qua interface vào Attendance; không phụ thuộc PrepClasses application service, không cycle. W05/API trực tiếp/list/roster/preview/mark/QR/transition/metadata/history/receipt đều kiểm class permission. Class write mới yêu cầu khóa active; replay receipt cũ được phép sau khóa đóng khi còn quyền hiện hành, không tái ghi. Class metadata không thể đổi sang unit scope hoặc ngày trước start/notBefore của buổi.

Course-level church fence và actor/session/version fences của Operations/Database hiện có là boundary cho race enroll/open/close/mark/revoke. CRUD không tự retry bằng key mới; CASresource412, stale preview409, outcome unknown503 giữ operationId; same-key replay status200 theo Operations v2. Transaction tests dùng Mongo replica set/Redis thật trong DB synthetic UUID. Không cần queue/cache/background job mới.

Prefix `[/owner]/churches/:churchId` dưới `/api/v1`:

| Endpoint | Contract |
|---|---|
| GET/POST `prep-classes/courses` | List signed keyset page1–100, q/state; create{name,startOn,teacher,baptismOn,lessons[]} |
| GET/PATCH `prep-classes/courses/:id` | Detail/version/planLocked/openSessions; patch đầy đủ metadata + reason + If-Match |
| POST `…/:id/activate`, `close`, `reopen` | `{reason}`, If-Match + idempotency |
| GET `…/:id/candidates` | Eligible Members picker q/limit/cursor, nguồn bounded/tenant scoped |
| GET/POST `…/:id/enrollments` | Progress page q/state/limit/cursor; create{memberId,confirmUnknown,reason nullable} |
| POST `…/:id/enrollments/:memberId/state` | `{state:studying|withdrawn,confirmUnknown,reason}`, If-Match enrollment |
| POST `…/:id/enrollments/:memberId/interview` | `{heldOn,interviewer,reason}`, If-Match enrollment; owner/pastor; no future day |
| GET/POST `…/:id/meetings` | Paged linked sessions; create{lessonId,kind,heldOn,location,memberIds}; regular memberIds=null, makeup unique1–2000IDs |
| GET `…/:id/history` | Audit-facing domain history signed time/id cursor, page1–100 |
| GET `prep-classes/operations/:operationId` | Namespace/actor/tenant/fresh permission; interview receipts retain interview permission requirement |
| GET `members/:memberId/prep-classes` | Protected W14 course links/state/interview summary, signed paged result |

POST/PATCH giữ Origin/CSRF. Body P3.3 tối đa192KiB để nhận curriculum/roster bounded; readJson mặc định16KiB ở các module khác không đổi. Dates là business day Asia/Ho_Chi_Minh. History/audit/ledger cùng transaction, safe receipt chỉ IDs/version; không tên/QR/interview details.

Read ports `Attendance.prepStatus/prepCredits/prepSessions` chạy trong transaction snapshot của caller. Progress aggregation filter church/course/closed tại Attendance, join own participants và group distinct member/lesson; tính cho trang học viên≤100. Meeting/W14/history lists có signed stable time/id cursors, không tải toàn bộ tenant rồi phân trang client. Indexes: courses page, enrollment unique/course-name page/member-history, regular partial unique/session unique/meeting page/history page; Attendance class-progress index. Keyset không hứa snapshot bất biến qua nhiều request.
