## Vòng đời và atomicity

1. Lưu nháp với input strict và CAS/If-Match, idempotency key; nháp được phép còn thiếu hoặc có xung đột để đối soát.
2. Chuẩn bị preview: đọc/fence nguồn hiện hành trong snapshot, render **ngoài transaction**, đọc lại quyền/nguồn/draft/template và chỉ stage khi context còn khớp.
3. Chốt: true confirmation và xác nhận đức tin khi cần; preview còn hạn, đúng actor/realm/church/draft version/context. Trong một transaction, đọc lại source fences, lưu edition cùng **cả hai binaries + hashes**, history/audit/ledger, promote draft, tiêu thụ preview và thay trạng thái bản trước nếu có.
4. Tạo phiên bản thay thế sinh nháp mới, giữ căn cước nguồn của lineage. Hai nháp cạnh tranh không thể cùng thay head; unique `(churchId,lineageId,revision)` và partial unique active head hỗ trợ invariant. Bản cũ giữ snapshot/bytes/history.
5. Thu hồi cần lý do và CAS; tăng resource version, lưu history/audit. Bản superseded/revoked không tải hoặc in mới được. Bytes đã tải trước đó không thể thu hồi khỏi máy người nhận.

Mã `NB-<lineage>/<revision>` chỉ là mã nội bộ, không thay số chứng nhận nghiệp vụ. Retry giữ nguyên idempotency intent. `OUTCOME_UNKNOWN` có actor-bound receipt, đọc lại/đối soát trước intent mới; `409 OPERATION_IN_PROGRESS` có thể thử lại hữu hạn bằng cùng key. Không tự retry bằng key mới. File GET audit bằng correlation ID mới, không tạo receipt giả cho thao tác đọc.

## API và nguồn file

Base `/api/v1/{owner/}churches/:churchId` (phần `owner/` tùy realm):

| Route dưới base | Phương thức / contract |
|---|---|
| `certificates/drafts` | GET keyset hoặc POST strict `{input,reason}` + idempotency |
| `certificates/drafts/:id` | GET hoặc PATCH cùng body + If-Match/key |
| `certificates/drafts/:id/prepare` | POST `{}` + If-Match/CSRF; không ghi edition |
| `certificates/drafts/:id/issue` | POST `{previewId,context,confirm:true,faithConfirmed,reason}` + If-Match/key |
| `certificates/drafts/:id/history` | GET keyset history |
| `certificates/editions` / `editions/:id` | GET summaries/detail; list không trả binaries/pages/full snapshot |
| `certificates/editions/:id/revise` / `revoke` | POST `{reason}` + If-Match/key |
| `certificates/editions/:id/files/pdf` / `docx` | GET `?version=N`, attachment, fresh auth/resource/version/state, no-store |
| `certificates/editions/:id/print` / `print-script` | GET `?version=N`, protected HTML/script, external CSS/fonts, no inline script |
| `certificates/operations/:id` | GET actor/church/resource-bound safe receipt |
| `members/:id/certificates` | GET keyset liên kết W14, kiểm tra member trong tenant |

POST/PATCH: exact origin, realm CSRF; body≤32KiB. Query/cursor signed, gắn filters/actor/policy; stable `(issuedAt,_id)` hoặc `(createdAt,_id)` và history `(occurredAt,_id)`, page≤100, mặc định25; không exact count mặc định. Indexed list/member/history; dữ liệu trả ra đã scope trước phân trang. File tên mã nội bộ, không họ tên. Không log input/nội dung file/dữ kiện bổ sung hoặc chữ ký.

## Render, fonts và giới hạn vận hành

- Pin `docx@9.15.3`, `pdfkit@0.20.2`, `@types/pdfkit@0.17.7`; dependencies theo lockfile. `api/certificates/fonts/sources.json` lưu URL/SHA256, giữ OFL; hash fonts được kiểm khi load. Be Vietnam Pro Regular/Bold và Lora SemiBold/Italic có glyph tiếng Việt, load offline. DOCX nhúng font đầy đủ; PDF subset font đã dùng. Không gọi converter bên ngoài hoặc runtime tải font.
- Chung snapshot/content và bounded A4 page model cho UI/HTML/PDF/DOCX; model wrap theo font metrics, prologue lặp mỗi trang, signature group ở trang cuối. PDF fixed, DOCX editable; ứng dụng không kiểm soát chỉnh sửa sau tải. Native Word có thể layout khác và chưa được nghiệm thu.
- **2 renderer/process**, **15s/job**, **10 pages**, **5MiB PDF+DOCX**, **8 live previews/church**, **15 phút TTL**; expiry kiểm trong truy vấn, không dựa vào TTL monitor. Child stdout≤8MiB gồm base64/artifacts/model, input qua stdin, không dữ kiện trong argv/stderr/log. Hết hạn/lỗi/limit → không tạo edition, draft vẫn dùng được.
- Render dùng **Bun child process disposable**, env rỗng, stream stdout bounded và kill khi timeout. Full-suite quan sát Bun1.3.1 segmentation fault tại ranh giới repeated Worker lifecycle (chưa kết luận internals Bun); đổi isolation sang process, không nâng version hoặc bỏ checks. Font/render/template fingerprint gắn preview; đổi code/template yêu cầu chuẩn bị lại preview. Binaries đã chốt giữ nguyên.
- PDF body được phân trang rõ, footer nằm ngoài body với margin phù hợp; QA phát hiện và sửa footer tự sinh trang phụ. Regression assertion so số PDF pages thật với model, không chỉ kiểm `%PDF-`.
- Quy mô workload local chỉ đo fixture thực qua API, HTTPS private CA; không suy production capacity/SLA/multi-replica. Không có scheduler/outbox/distributed admission; multi-replica/global render cap chưa qualification.
